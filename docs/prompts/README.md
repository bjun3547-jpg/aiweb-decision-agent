# Prompt 快照（AI 协作过程留痕）

> 传智杯官网要求：「保留完整、细粒度的 Git 提交历史（禁止一次性提交……每次提交应对应
> **一次与 AI 的核心对话** 或 **一个功能模块的落地**）」，并「重点核查作品原创性与
> **开发过程可复现性**」。
>
> 这个目录就是用来满足这条要求的：**每次让 AI 帮你做一个关键决策，就在这里留一份快照。**

---

## 怎么用

每完成一次重要协作，新建一个文件：

```
docs/prompts/YYYY-MM-DD-NN-简短主题.md
```

模板：

```markdown
# <主题>

- 日期：
- 参与人：
- AI 工具 / 模型：

## 1. 我的意图
（一句话说清这次要解决什么）

## 2. 我给的 Prompt
（原样粘贴，不要美化）

## 3. AI 的回答要点
（只摘关键结论，不要全文粘贴几万字）

## 4. 我做了什么判断
- 采纳了什么、为什么
- **否定了什么、为什么** ← 这一段最有价值，能证明是你在做决策，不是 AI 在替你做

## 5. 落到哪个提交
commit: <hash> <message>
```

## 为什么这件事值得认真做

1. **它是明确的评分项**，而且是「核查」项，不是「加分」项 —— 做不好直接扣分。
2. **它能证明原创性**。评审看到你们第 3 天的对话里就已经推翻了 AI 的某个方案，
   比看到一份完美但来路不明的代码有说服力得多。
3. **它逼你们复盘**。「否定了什么、为什么」这一栏写不出来，说明你在照抄。

> ⚠️ 不要事后补写。Git 提交时间戳会说话，补写的痕迹一眼可见。
