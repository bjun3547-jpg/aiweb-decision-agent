# 部署指南（10/21 任务）

> 目标：让评委/队友用手机 4G 能打开 `https://` 公网地址，看到完整界面并跑通一次排班。
> 判据（来自 `01-执行手册.md` §五 A 的任务卡）：**公网地址手机 4G 能打开 + 断网时显示人话提示**。

---

## 0. 四条路线怎么选

| 路线 | 耗时 | 地址稳定 | 适合 | 代价 |
| --- | --- | --- | --- | --- |
| **A. ngrok** | **10 分钟** | ❌ 每次重启都变 | 现在就要一个能点的链接 | 电脑必须一直开着 |
| B. Cloudflare Tunnel | 15 分钟 | ❌ 同上 | A 的备选（不用注册） | 同上 |
| C. Docker + 云服务器 | 2 小时 | ✅ | 长期演示、视频录制 | 要买服务器（约 30 元/月） |
| D. Render / Railway | 40 分钟 | ✅ | 连 GitHub 自动部署 | 国内访问慢，冷启动久 |

**建议顺序**：今天先做 A（拿到可用链接，不阻塞其他事），周末再补 C（录视频时更稳）。

---

## 1. 路线 A：ngrok（推荐先做这个）

### 1.1 本地先把服务跑起来

```powershell
cd F:\AIWeb\backend
..\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

看到 `Uvicorn running on http://127.0.0.1:8000` 就对了。**这个窗口不要关。**

### 1.2 另开一个窗口装 ngrok

```powershell
winget install ngrok.ngrok
```

装完**关掉终端重开**（让 PATH 生效），然后验证：

```powershell
ngrok version
```

### 1.3 拿 authtoken 并绑定

1. 注册 <https://dashboard.ngrok.com/signup>（GitHub 账号可直接登录）
2. 登录后左侧 **Getting Started → Your Authtoken**，复制那串 `2abc...`
3. 执行：

```powershell
ngrok config add-authtoken 你复制的那串
```

### 1.4 开隧道

```powershell
ngrok http 8000
```

终端会显示：

```
Forwarding    https://xxxx-xx-xx-xx-xx.ngrok-free.app -> http://localhost:8000
```

**那个 `https://...ngrok-free.app` 就是公网地址。** 手机 4G 打开验证。

### 1.5 注意三件事

- **免费版每次重启地址都会变**，所以录视频前要重新生成一次并记下来。
- 免费版首次访问会有一个 ngrok 的提示页，点 `Visit Site` 才进得去——**录视频时要注意别录到这一步**，或者提前点过再录。
- **电脑不能休眠**。录视频/答辩期间把电源计划改成「从不睡眠」。

## 2. 路线 B：Cloudflare Tunnel（备选，不用注册）

如果 ngrok 装不上或注册不了：

```powershell
winget install Cloudflare.cloudflared
cloudflared tunnel --url http://localhost:8000
```

终端会打印一个 `https://xxx.trycloudflare.com` 地址，直接用。同样每次重启会变。

---

## 3. 路线 C：Docker（长期稳定）

仓库根目录已经有 `Dockerfile`、`.dockerignore`、`docker-compose.yml`。

### 3.1 本地验证镜像能跑

```powershell
cd F:\AIWeb

# 构建（国内默认走清华源，镜像约 700MB，首次 3–5 分钟）
docker build -t aiweb-agent .

# 运行：密钥从环境变量注入，不写进镜像
docker run -p 8000:8000 -e DEEPSEEK_API_KEY=sk-你的key aiweb-agent
```

打开 <http://127.0.0.1:8000>，和本地开发时一模一样。

或者用 compose（会读 `backend/.env`）：

```powershell
docker compose up --build
```

### 3.2 推到云服务器

以腾讯云轻量应用服务器 / 阿里云 ECS（Ubuntu 22.04）为例：

```bash
# 服务器上
git clone https://github.com/bjun3547-jpg/aiweb-decision-agent.git
cd aiweb-decision-agent
docker build -t aiweb-agent .
docker run -d --name aiweb \
  -p 80:8000 \
  -e DEEPSEEK_API_KEY=sk-你的key \
  --restart unless-stopped \
  aiweb-agent
```

然后浏览器打开 `http://服务器公网IP`。

> 用 80 端口是因为它不用额外开放安全组。**注意**：国内服务器绑定域名需要备案，
> 但**直接用 IP 访问不需要**——比赛演示用 IP 就够了。

### 3.3 云服务器要开放端口

在控制台的「防火墙 / 安全组」里放行 TCP 80（或你用的那个端口）。
**这一步最容易忘**，症状是「本地能开、公网打不开」。

## 4. 路线 D：Render / Railway（连 GitHub）

以 Render 为例：

1. <https://render.com> 注册，`New → Web Service`，选这个 GitHub 仓库
2. Render 会自动识别根目录的 `Dockerfile`，选 **Docker** 而不是 Python
3. 环境变量里加 `DEEPSEEK_API_KEY`
4. 部署完拿到 `https://xxx.onrender.com`

**注意**：免费档 15 分钟无访问会休眠，下次访问要等 30–60 秒冷启动。
答辩前 5 分钟先打开一次把它唤醒。

## 5. 密钥安全：三条铁律

公网部署最容易在这里翻车。

1. **`.env` 永不进仓库。** `.gitignore` 第 4 行 `*.env` 挡着，已用 `git log --all -- "*env"` 验证过历史里没有。
2. **密钥永不进镜像。** `.dockerignore` 里显式排除了 `.env` 和 `**/.env`，Dockerfile 里没有任何 `COPY .env`。
3. **密钥只从环境变量注入。** `docker run -e`、平台的环境变量面板、`docker compose` 的 `env_file`（本地）——三条路都行，写死进代码或镜像不行。

> 如果密钥曾经不小心提交过：立刻去 <https://platform.deepseek.com/api_keys> 吊销重发。
> 提交历史里的密钥即使后来删了文件，`git log -p` 依然能翻出来。

## 6. 部署后验证清单（逐条打勾）

在**手机 4G**（不是 WiFi）上逐项确认：

- [ ] 打开公网地址，首页正常显示，不是白屏
- [ ] 右上角两个徽标：**「大模型已连接」** 和 **「OR-Tools CP-SAT」** 都亮着
- [ ] 粘贴示例需求 → 点「开始排班」→ 六步轨迹逐条亮起
- [ ] 排班表出现，早班/晚班不同颜色，28 个班次
- [ ] 决策说明有中文文字（不是空白、不是英文）
- [ ] what-if 输入「如果张伟下周只能上 2 天班会怎样」→ 表格变色、显示「取消 X / 新增 Y」
- [ ] 打开 `公网地址/docs`，API 文档能显示
- [ ] 打开 `公网地址/api/health`，返回 `"status":"ok"`

**断网测试**（手册要求的「断网时显示人话提示」）：

- [ ] 拔掉网线/关掉 WiFi 后再点「开始排班」，界面显示的是**中文可读提示**（如「请求失败：…」），不是浏览器默认的 `Failed to fetch` 白屏

## 7. 常见坑

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| 本地能开，公网 404/超时 | 云服务器安全组没放行端口 | 控制台放行 TCP 80 |
| 首页白屏 | 静态文件没打进镜像 | 检查 `COPY backend /app/backend`，`app/static` 要在里面 |
| `/api/health` 返回 `configured:false` | 环境变量没传进去 | 检查 `docker run -e` 或平台的环境变量面板 |
| 排班报 402 | 余额不足 | <https://platform.deepseek.com> 充值 |
| ngrok 地址打开是提示页 | 免费版首次访问确认页 | 先手动点 `Visit Site`，再录视频 |
| Docker 构建卡在 `pip install` | 国内网络 | 已默认清华源；仍慢就加 `--build-arg PIP_INDEX=https://mirrors.aliyun.com/pypi/simple/` |
| 镜像拉不下来 | Docker Hub 国内不稳定 | 配镜像加速器，或把 `FROM python:3.13-slim` 换成 `FROM docker.m.daocloud.io/library/python:3.13-slim` |

## 8. CORS 要不要改？

**不用改。** `main.py` 里虽然写着 `allow_origins=["*"]` 并注释「部署时改成前端域名」，
但前端页面是由同一个 FastAPI 进程托管的（`app.mount("/static", ...)` + `GET /`），
属于**同源请求**，CORS 根本不生效。

只有当有人把前端单独部署到另一个域名时，才需要收紧这个配置。比赛期间保持现状即可。
