### 10/24 周六

**上午：建评测集（三人一起，3 小时）**

新建 `backend/benchmark/cases.json`，**30 道题**，按这个配比：

| 类型 | 数量 | 怎么设计 |
|---|---|---|
| 常规场景 | 18 | 不同规模：5 人/3 天、7 人/7 天、12 人/14 天；不同班次：2 班、3 班（加夜班） |
| 边界场景 | 6 | 单人单日、满负荷（每人每天都上）、有人整天不可用、技能只有一人具备 |
| 冲突场景 | 6 | 需求超承载、技能无人、休息天数过高——**检验自愈能力** |

每道题的格式：

```json
{
  "id": "case-01",
  "type": "normal",
  "text": "（自然语言输入）",
  "expect_status": "OPTIMAL",
  "difficulty": "easy"
}
```

**下午：写评测脚本**

新建 `backend/benchmark/run_benchmark.py`：读 cases.json → 逐个跑 `agent.run()` → 输出 `report.csv`（id、状态、耗时、班次数、是否有冲突诊断）。
